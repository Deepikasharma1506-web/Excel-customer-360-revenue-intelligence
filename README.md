# Customer 360 & Revenue Intelligence Dashboard (Excel)

An advanced Excel portfolio project combining sales analytics, profitability reporting, customer segmentation, and an executive dashboard.

> **Dataset notice:** All order and customer records are synthetic and created for portfolio demonstration only.

## Features
- Executive KPI dashboard with revenue, profit, completed orders, unique customers, average order value, and profit margin
- Region selector to focus headline KPIs
- Monthly revenue and profit trend chart
- Revenue by product category and sales channel
- RFM-style customer segment summary (Champions, Loyal Customers, Recent Customers, At Risk, Needs Nurturing)
- Separate Raw Data, Clean Data, Analysis, Customers, Start Here, and Data Dictionary sheets
- Excel tables, formula-driven summaries, charts, and structured documentation

## Excel Skills Demonstrated
Excel Tables, `SUMIF`, `SUMIFS`, `COUNTIF`, `COUNTIFS`, `IFERROR`, data validation, KPI design, charting, business metric definitions, and analytical storytelling.

## Workbook Structure
| Sheet | Purpose |
|---|---|
| `Start_Here` | Project guide |
| `Dashboard` | Executive KPI cards and charts |
| `Raw_Data` | Generated order records, including returned/cancelled statuses |
| `Clean_Data` | Completed orders prepared for analysis |
| `Analysis` | Monthly, category, channel and RFM summary tables |
| `Customers` | Customer master data |
| `Data_Dictionary` | Column definitions and metric explanations |

## How to Use
1. Download `workbook/Customer_360_Revenue_Intelligence.xlsx`.
2. Open it in Microsoft Excel.
3. Start at `Dashboard`.
4. Use the region dropdown in cell `C5` to change the KPI focus.
5. Explore `Analysis` for detailed summary tables.

## Important Limitations
- Data is simulated, not from a real retailer.
- The RFM-style customer labels are heuristic portfolio examples, not validated marketing segments.
- The region selector changes KPI cards; charts show the overall dataset for transparent comparison.
- No macros, external data connections, or Power BI dependencies are required.
